# Unikas Spa y Peluquería

Sitio web demo para **Unikas Spa y Peluquería** (peluquería y spa para mujeres en Arequipa).
HTML + CSS + JavaScript puro: sin instalaciones ni dependencias.

## Ver el proyecto
- Local: abre `index.html` con doble clic.
- GitHub Pages: sube la carpeta a un repositorio → *Settings → Pages* → Branch `main`, carpeta `/root` → guarda. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Qué incluye
- Hero con tarjeta destacada, menú adaptable a móvil y preloader con el logo.
- Servicios con filtros (Cabello, Color, Tratamientos, Spa & Uñas).
- Reserva online en 3 pasos (servicio → día y hora → datos) que envía la cita por WhatsApp al +51 972 024 022.
- Galería con zoom, preguntas frecuentes, cupón de primera visita, mapa y botón flotante de WhatsApp.

## Personalizar
- **Precios y servicios:** arreglo `SERVICES` al inicio de `js/main.js`.
- **Número de WhatsApp:** constante `WHATSAPP` en `js/main.js` y los enlaces `wa.me` de `index.html`.
- **Dirección, horario y redes:** sección `#contacto` de `index.html`.
- **Imágenes:** carpeta `img/`.

> Los horarios ocupados del calendario son simulados (demo). Los precios de Botox capilar, peinados, uñas, facial y Día Unikas son referenciales: confírmalos con el cliente.
